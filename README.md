# Gakumas Music Extractor

「学園アイドルマスター」PC版のローカルデータを調べ、音楽アセットを検索・抽出するWindows向けGUIツールです。

## 配布版の動作条件

- Windows 11 x64
- 学マスPC版を一度以上起動し、最新データまで更新済みであること
- 学マスのデータが通常どおりローカルPCに保存されていること

配布版にはPython 3.12、PySide6、GkmasObjectManager、vgmstream、FFmpeg、UnityPyと必要なPythonパッケージを同梱しています。Pythonや外部ツールを別途インストールする必要はありません。Unity AudioClipもvgmstreamで変換し、FMODランタイムは同梱していません。

## ダウンロード

[GitHub Releases](https://github.com/Graynish-50124/gakumas-music-extractor/releases)から最新版を取得できます。通常はone-folder版を推奨します。

## どちらを使うか

### one-folder版（推奨）

1. `GakumasMusicExtractor-one-folder.zip`を任意の場所へ展開します。
2. `GakumasMusicExtractor`フォルダ内の`GakumasMusicExtractor.exe`を起動します。

`_internal`フォルダも実行に必要です。EXEだけを移動せず、フォルダごと利用してください。起動が速く、問題の切り分けもしやすいため、通常はこちらを推奨します。

### one-file版

`GakumasMusicExtractor-one-file.zip`を展開し、中の`GakumasMusicExtractor.exe`を起動します。アプリ本体はこのEXEだけで動作します。初回を含む各起動時に内蔵ランタイムを一時フォルダへ展開するため、one-folder版より起動に時間がかかります。署名のない自作EXEなので、Windows SmartScreenやセキュリティ製品が確認を表示する場合があります。

## 基本的な使い方

1. アプリを起動します。既定ではローカルの`octocacheevai`を自動検出し、復号・解析します。
2. 絞り込みカードでキャラクター、種類、歌唱、短縮版、検索条件を指定します。「短縮版」は既定で「通常版のみ」です。「すべて／通常版のみ／短縮版のみ」から選べ、「条件をクリア」でも通常版のみに戻ります。
3. 抽出する行をチェックします。選択セル内のどこでもクリックでき、Shift+クリックで連続範囲をまとめて選択／解除できます。表の上で左ボタンを押したままドラッグすると青い範囲へチェックが入り、青い範囲から外れた行のチェックは解除されます。「表示中をまとめて選択／解除」も利用できます。
4. 「抽出」を押し、保存形式、アルバムアート、ファイル名形式、出力先を選びます。
5. 必要なら「関連するライブ音源も取得」を有効にします。

既定の出力先は`%USERPROFILE%\Music\GakumasExtracted`です。ゲームデータを誤って上書きしないよう、学マスのデータフォルダ内は出力先にできません。

## 検出・表示するデータ

- 通常楽曲、キャラクター曲、ユニット曲、ライブ音源、BGM
- 歌入り / インスト
- ACB、AWB、MP3、Unity AssetBundle内ライブ音源
- 曲ごとに対応する1024×1024のゲーム内アルバムアート
- `normal`と`true`を含むライブのバージョン違い。`normal-*`は短縮版、`true-*`は通常版として一覧の「短縮版」列に表示
- 未知の将来IDも、既知名を推測せず内部IDのまま表示

同じ曲・キャラクター・種別・歌唱・バージョンに属するACB/AWB/MP3は1行にまとめます。絞り込みカードには「表示中／全件」の件数を表示します。短縮版フィルターを「通常版のみ」にすると、一覧と「関連するライブ音源も取得」の両方から短縮版を除外します。表の列幅と並び順はドラッグで調整でき、セルにカーソルを置くと省略前の内容を確認できます。行をダブルクリックすると、短縮版判定、内部アセット名、サイズ、関連ライブを確認できます。

## 保存形式

- WAV: ゲーム内のHCA等の圧縮音源をPCM WAVへデコード
- AWB: ゲームに保存された元のAWBをそのまま保存
- MP3: ManifestにMP3として収録されているデータを保存
- ACB: ゲームに保存された元のACBをそのまま保存
- アルバムアート: 元PNGを保存し、同じ画像をWAV／MP3へ埋め込み

WAVはゲーム内圧縮音源をデコードしたものです。CDや配信サービスのロスレスマスターを復元するものではありません。

WAVのRIFF INFOには、タイトル（`INAM`）として曲名、アーティスト（`IART`）としてキャラクター名を書き込みます。アルバムアートを有効にすると、WAV／MP3へID3のフロントカバー画像も埋め込みます。日本語Windowsで文字化けしない文字コードを使用し、アルバム名等のタグは新規追加・変更しません。ユニット曲は、判別できるメンバー名を「・」で連結します。プレーヤーによってはWAV内の画像を表示しない場合がありますが、同名のPNGも保存されます。

## ファイル名形式

抽出時に次の3形式から選べます。既定は1番目です。

1. `楽曲名＿キャラクター名［差分情報］`
2. `元のファイル名そのまま`
3. `楽曲名［差分情報］`

通常の歌入りは差分表記を付けません。ライブは`［ライブ］`、短縮版は`［ライブ・短縮版］`、インストは`［インスト］`を末尾へ付けます。例: `Fluorite＿有村麻央.wav`、`Fluorite＿有村麻央［ライブ］.wav`。曲名が未登録の場合は内部名を使用します。同じ名前が複数の抽出対象で衝突する場合だけ、キャラクター名、ライブバージョン等の識別子を末尾に補い、上書きや抽出漏れを防ぎます。Windowsでファイル名に使えない記号は、読みやすい全角記号へ置換します。選択した形式は次回の既定値として保存され、設定画面からも変更できます。

## Manifestの扱い

既定では`%USERPROFILE%\gakumas\octo\pdb\...\octocacheevai`から、更新日時と内容を基に利用可能なPC版Manifestを自動検出します。先頭管理バイトを除去し、学マスPC版の方式でAES-CBC復号、MD5検証、Protobuf解析を行います。

設定画面では次を変更できます。

- 学マスデータフォルダまたは`octocacheevai`の手動指定
- ローカルPC版優先 / オンラインPC版
- ローカル読込失敗時だけオンライン版へフォールバック
- 既定の保存形式、ファイル名形式、出力先、表示テーマ、起動時スキャン

「システム」テーマはWindowsのライト／ダーク設定へ追従し、それぞれに最適化したコントラストで表示します。

ローカルManifestと対象アセットがキャッシュ済みなら抽出はローカルだけで完結します。オンライン設定やキャッシュ不足時の取得にはネットワーク接続が必要です。

## 名前マッピング

設定とマッピングは次に保存されます。

`%APPDATA%\GakumasMusicExtractor`

- `settings.json`: アプリ設定
- `characters.json`: キャラクターIDと表示名
- `song_names.json`: 曲IDと表示名

配布版にはゲームのMusicマスターにある`gameVersionAssetId`と正式タイトルから生成した曲名カタログを同梱しています。通常楽曲、キャラクター専用曲、ユニット曲、関連ライブは、抽出する前から一覧の「曲名」列へタイトルが表示されます。

未知IDや曲名は推測しません。マスターに対応がないものだけ内部ID表示へ戻ります。ユーザー側の`song_names.json`へ追加した値は同梱カタログより優先されます。編集後は「再スキャン」で即時に読み直します。

開発時に最新のMusicマスターから同梱カタログを再生成する場合:

```powershell
.\.venv\Scripts\python.exe .\tools\update_song_titles.py
```

## トラブルシューティング

### Manifestが見つからない

学マスPC版を起動し、タイトル画面まで進めて最新データの更新を完了してください。その後「再スキャン」を実行します。保存場所を変更している場合は、設定から`octo`フォルダまたは`octocacheevai`を指定してください。

### 曲は見えるが抽出できない

対象曲をゲーム内で一度再生するなどしてキャッシュさせてから再試行してください。設定でオンラインフォールバックを有効にすると、不足アセットをPC版配布元から取得できる場合があります。

### Windowsが実行を止める

本配布物はコード署名されていません。GitHubの公式Releaseから取得したことを確認したうえで、Windowsの詳細表示から実行してください。セキュリティ製品で隔離された場合はone-folder版を展開し直してください。

### 処理が遅い

Manifestの初回解析、複数曲のWAV変換、one-file版の起動時展開には時間がかかります。進捗バーとログを確認してください。抽出は安全な処理単位でキャンセルできます。

## 開発・再ビルド

開発時のみPython 3.12が必要です。PowerShellでプロジェクト直下から実行します。

```powershell
.\tools\fetch_ffmpeg.ps1
.\build.ps1
```

`build.ps1`は仮想環境の準備、依存関係の導入、pytest、one-folderビルドと実データ受け入れテスト、one-fileビルドと同テストを順に実行します。one-folderだけの場合は`.\build.ps1 -SkipOneFile`を使います。

開発実行:

```powershell
.\run.ps1
```

診断用オプション:

```powershell
.\.venv\Scripts\python.exe .\src\main.py --self-test
.\.venv\Scripts\python.exe .\src\main.py --scan-only
```

受け入れテストではローカルManifestの解析に加え、代表曲のAWB/WAV、アルバムアート、関連する`true`ライブWAVを実際に生成し、ファイルシグネチャ、曲名・アーティスト、埋め込み画像、アルバム名タグを追加していないことまで確認します。生成したゲームアセットはビルド成果物へ含めません。
